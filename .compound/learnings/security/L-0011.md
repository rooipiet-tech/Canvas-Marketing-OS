statement: GitHub Actions' OIDC token presents a different `sub` (subject) claim depending on the triggering context — a branch/ref job presents `repo:<org>/<repo>:ref:refs/heads/<branch>`, a pull_request job presents `repo:<org>/<repo>:pull_request`, and a job scoped to a GitHub Environment (via `environment: <name>`) presents `repo:<org>/<repo>:environment:<name>` — NOT the ref-based subject, even though the same workflow file and same branch trigger it. An Azure AD App Registration's OIDC federated credential must match the exact subject presented; a federated credential registered only for the ref-based subject will NOT authenticate a job gated behind `environment: <name>`, since that job presents a different subject entirely. Each context a workflow actually uses needs its own federated credential.

evidence: deploy-infra.yml's `deploy` job is gated by `environment: cmos-dev`, so it authenticates via OIDC using the `environment:cmos-dev` subject — distinct from the `ref:refs/heads/main` subject presented by the ungated jobs/workflows (azure-provider-registration.yml, deploy-infra.yml's own `what-if` job) that also push-trigger on main. A federated credential covering only the ref-based subject does not cover the environment-gated job.

catch_next_time: When adding or auditing OIDC federated credentials for a GitHub Actions → Azure AD app, enumerate every distinct trigger context a workflow's jobs actually run under (branch push, pull_request, environment-gated job, tag, etc.) and register one federated credential per exact subject. Register from the exact subject presented in the actual OIDC failure/assertion (visible in the failed `azure/login@v2` error or the federated-credential-mismatch message), never from a generic docs example — org/repo IDs are embedded and immutable per credential. Treat "add an `environment:` gate to a workflow job" and "add the matching `environment:<name>` federated credential" as one atomic change — never land one without the other, or the newly-gated job will fail OIDC login the first time it runs.
