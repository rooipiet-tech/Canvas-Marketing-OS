The design of record changed under this audit's feet, deliberately

The 4 September audit measured the build against the v1 .docx. Blueprint v2 landed the same day (PR #147 for the v1 register; PR #148, open and unmerged at this baseline, for v2 itself) and changes the operating principle it is graded against: agents author, humans ratify, with autonomy earned per function from decision telemetry rather than granted by fiat.

This is not a re-skin of the 4 September documents. Every row in this audit is re-derived against docs/blueprint/agentic-marketing-engine-v2.md, not the July .docx. Where v2 changes nothing about a class the 4 September audit already counted, that is stated explicitly rather than silently re-copied — see §1's own scope note.

What v2 does not change

Downstream autonomy (publish, claim, spend) is not loosened anywhere in v2; it is earned per §G2. The seven non-negotiable approval gates are unchanged in substance. Nothing shipped in PR #148 is wired into a running loop — every one of the 15 new functions, 3 new loops and 4 new contracts is scaffolded, a new state this audit adds to the five-state model because "deferred" (not started) and "built" (a loop reaches it) both describe it badly.

Session process audit — s0 to s13, no new sessions

The 4 September audit enumerated 13 session branches (s0–s11, s13; s12 never existed). git branch -a at this baseline shows the identical set — session/s0-foundation through session/s13-website, no session past s13. There is nothing to extend this pass; the 4 September session inventory (418 acceptance criteria, 101 out-of-scope declarations, 14 amendments across 13 specs) stands unchanged.

One process note specific to this pass: the blueprint-v2 landing (PR #148) and this audit were both produced directly against main via a branch (docs/blueprint-v2-register), not as a session/{id} worktree with its own .loop/spec.json. That is consistent with how this request itself was framed (three sequential jobs in one conversation, not a spec-driven session), but it means this work carries none of the process artefacts (plan.md, review.json, stated confidence) the session table above credits every other delivery with. Worth naming rather than leaving implicit.
