Two discrepancies resolved, not merely re-measured

The prior audit (PR #149) left two live-number discrepancies unreconciled and one field name unresolved. This pass resolves all three, live, not by inference.

  • Brand Steward pass rate and unsupported-claim count. Two independent reads, 1h40m apart this session, agree exactly (64.1%, 31). caj-vault-retention-expiry — the hypothesis raised last time — has never run, ever (confirmed: trigger type Manual, zero executions). The 09:49 UTC read from the original session is the outlier, and that session's own methodology note already documents why: an override-application failure mode (L-0023's class) it admits hitting twice.
  • smoke-test-v1 was never a real field. The actual tag is agent_runs.agent_name = 'smoke-agent' — 3,550 rows in 30 days, 100% pending, matching the qualitative finding under its real name.
  • The discovery-trigger diagnosis from PR #150 was wrong. Its role assignment exists; the diagnostic command (az role assignment list --assignee) is unreliable in this environment and returns [] even for a trigger with 3 consecutive successful runs. The real cause: an RBAC-propagation race 0.35 seconds after the grant was created. See §3.
